# Developer Portfolio and DailyWork

My full-stack portfolio website, with project showcases, technical skills, contact information, posts, and a DailyWork progress tracker.

## Highlights

- Responsive multi-page portfolio
- Detailed project and skill pages
- DailyWork logs with pagination and progress tracking
- Admin authentication and same-day editing
- Post feed and individual post pages
- Separate React frontend and Express/MongoDB backend

## Tech stack

React, Vite, Tailwind CSS, Framer Motion, Node.js, Express, MongoDB, JWT

## Run locally

```bash
cd backend && npm install
cp .env.example .env
npm run dev

cd ../frontend && npm install
npm run dev
```
